# Data

`ranchi_nasal_morphometry.csv` is the de-identified analysis table used by the reproducibility workflow. It contains generated subject identifiers and no names, contact details, or other direct identifiers.

Public redistribution of participant-level human data must be consistent with the applicable institutional ethics and data-governance determination. If public redistribution is not authorized, remove the CSV before making a public release; the source code, tests, app, and aggregate generated outputs can still be distributed.
